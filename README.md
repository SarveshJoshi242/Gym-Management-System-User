# GymPlus - Fitness Management System

A premium, full-stack fitness dashboard featuring an AI-powered personal trainer, daily calorie/water tracking, automated workout scheduling, and real-time visualization of your progress.

## Tech Stack
* **Backend**: Spring Boot 3.2.x (Java)
* **Database**: MySQL (JPA / Hibernate)
* **Frontend**: Vanilla HTML5, CSS3 (Glassmorphism design), and JavaScript
* **AI Integration**: Google Gemini LLM API

## Requirements
* Java 17 or higher
* Maven 3.6+
* MySQL 8.x
* A Gemini API key (for the AI features)

## Setup & Run Instructions

### 1. Database Setup
Make sure your local MySQL server is running. Create a database called `gymplus`:
```sql
CREATE DATABASE gymplus;
```
*(The schema and tables will be automatically generated by Spring Boot Hibernate when the app starts).*

### 2. Configure Environment
Update the `src/main/resources/application.properties` file with your MySQL credentials and your Gemini API key:
```properties
spring.datasource.url=jdbc:mysql://localhost:3306/gymplus
spring.datasource.username=root
spring.datasource.password=your_password
gemini.api.key=YOUR_ACTUAL_API_KEY
```

### 3. Run the Application
Navigate to the root directory of the project and run the Spring Boot server using Maven:

**For Windows:**
```powershell
mvn spring-boot:run
```

**For Mac/Linux:**
```bash
mvn spring-boot:run
```

### 4. Access the Dashboard
Once the server has successfully started, open your web browser and navigate to:
```text
http://localhost:8080
```

From here, you can register a new test user, log in, and start tracking your fitness goals!
